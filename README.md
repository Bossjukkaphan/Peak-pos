# Peak POS

ระบบ POS และบริหารจัดการสำหรับยิมเพิ่มส่วนสูงเด็ก — ครอบคลุมการขายคอร์ส, การจอง/ตารางเทรน, การตัดครั้ง, การติดตามผลการเติบโต, ค่าเทรนโค้ช และมุมมองลูกค้าผ่าน LINE OA

## เอกสาร

- [พิมพ์เขียวระบบ (Blueprint)](docs/pos-blueprint.md) — วิเคราะห์จาก Google Sheets วางแผนของทีม และข้อเสนอฟีเจอร์ครบทั้ง 3 มุมมอง (ผู้บริหาร / พนักงานหน้าร้าน / ลูกค้า) พร้อมโครงสร้างข้อมูล กฎธุรกิจ และแผนพัฒนา 3 เฟส

## สถานะ

อยู่ระหว่างขั้นวางแผน (brainstorming / requirements) — ยังไม่เริ่มพัฒนาโค้ด
