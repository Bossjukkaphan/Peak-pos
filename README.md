# Peak POS

ระบบ POS และบริหารจัดการสำหรับยิมเพิ่มส่วนสูงเด็ก — ครอบคลุมการขายคอร์ส, การจอง/ตารางเทรน, การตัดครั้ง, การติดตามผลการเติบโต, ค่าเทรนโค้ช และมุมมองลูกค้าผ่าน LINE OA

## เอกสาร

- [พิมพ์เขียวระบบ (Blueprint)](docs/pos-blueprint.md) — วิเคราะห์จาก Google Sheets วางแผนของทีม และข้อเสนอฟีเจอร์ครบทั้ง 3 มุมมอง (ผู้บริหาร / พนักงานหน้าร้าน / ลูกค้า) พร้อมโครงสร้างข้อมูล กฎธุรกิจ และแผนพัฒนา 3 เฟส

## การรันระบบ (เฟส 1 MVP)

```bash
npm install
npm run dev        # เปิด http://localhost:3000
```

ฐานข้อมูลเป็น SQLite สร้างอัตโนมัติที่ `data/peak.db` พร้อม seed ข้อมูลตัวอย่างจากชีทวางแผน (สมาชิก PL001–PL003, โค้ช 3 คน, คอร์ส 1/3/12 เดือน) — ลบไฟล์นี้เมื่อต้องการเริ่มใหม่

## ขอบเขตเฟส 1 ที่ทำแล้ว

- **Dashboard** — สมาชิก, รายได้เดือนนี้, booking/เทรนวันนี้, คอร์สใกล้หมด (≤6 ครั้ง), งานตามต่อค้าง, สรุปโค้ชวันนี้
- **ตารางเทรนรายวัน** — slot 30 นาที แยกคอลัมน์ต่อโค้ช, จองคิว (เทรน/ทดลอง/Consult/วัดตัว), เช็คอินตัดครั้งอัตโนมัติ (FIFO, กันติดลบ), ไม่มา/ยกเลิก, ธงแดงเมื่อครั้งใกล้หมด
- **สมาชิก** — สมัครใหม่ (ออกรหัส PLxxx อัตโนมัติ), แยกข้อมูลเด็ก/ผู้ปกครอง, ข้อระวังเด่นชัด, ประวัติคอร์ส/ชำระเงิน/ledger, บันทึกวัดตัวพร้อมผลต่างส่วนสูง
- **ขายคอร์ส (POS)** — ของแถม/ส่วนลด, Cash/Card/QR, เลขใบเสร็จรันอัตโนมัติ, ครั้งเข้าบัญชีผ่าน ledger
- **Trial / ตามต่อ** — บันทึก lead, ผลการขาย, งานตามต่อรอบ 1-2-3 สร้างอัตโนมัติ (+3 วัน)
- **โค้ช** — เรทต่อครั้ง, จำนวนเทรนรายวัน/รายเดือน, ค่าเทรนคิดจากการเช็คอินจริง

นโยบายเริ่มต้นที่ปรับได้ในตาราง `settings`: เตือนเมื่อเหลือ ≤6 ครั้ง (`low_credit_threshold`), no-show ไม่หักครั้ง (`no_show_deducts`)

## Stack

Next.js (App Router, Server Actions) + better-sqlite3 — เตรียมย้ายขึ้น Supabase/PostgreSQL ในเฟสถัดไปตาม blueprint

## การเข้าถึง (เพิ่มในรอบอัปเดต)

- **หน้าแอดมิน** (Dashboard, สมาชิก, ขายคอร์ส ฯลฯ) ต้องใส่ PIN ก่อนเข้า — ค่าเริ่มต้น `1234` เปลี่ยนได้ด้วย env `ADMIN_PIN`
- **บอร์ดโค้ช** `/board` เปิดดูได้โดยไม่ต้องใส่ PIN — เห็นเฉพาะตารางสอน (ชื่อ เวลาเริ่ม–จบ ประเภท สถานะ) ไม่มีข้อมูลคอร์ส/รายได้
- ตารางเทรนมีปฏิทินรายเดือน กดวันเพื่อดูตารางวันนั้น ตัวเลขใต้วัน = จำนวน booking
